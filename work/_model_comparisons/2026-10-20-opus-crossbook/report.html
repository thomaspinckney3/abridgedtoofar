Can the pipeline generate its own preservation instructions?

How the instructions were generated

1. Whole book → plans
Opus reads the complete original book and uses one generic rubric to generate plans for the selected chapters.

2. Code validates
Quoted evidence must exist, protected text must fit the 25% cap, and section weights become budgets summing exactly to target. A bounded repair step fixes rejected evidence from retrieved source passages.

3. Source + plan → draft
A separate call abridges each original chapter using the validated plan and compact operational instructions.

4. Measure and review
Count words, verify protected text and inspect continuity, source fidelity, style and planning choices. These first drafts were measured and rejected; no trim pass was run.

No chapter-specific preservation choices were written or edited by the coding assistant. Existing abridgments were withheld from both model stages and retained only for comparison. Model and effort: Opus 5.5, medium. The four chapter choices and their existing word targets were selected before generation.
