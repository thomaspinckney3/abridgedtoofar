Draft, count, evaluate cuts, revise

Experiment design

1. Whole book → plans
Opus reads each complete original book and generates preservation plans at the original per-chapter targets. The same plan and target are used for both passes.

2. Code validates
Quoted evidence must exist, protected text must fit the 25% cap, and section weights become budgets summing exactly to target. Evidence checks must pass before drafting; any repair history is recorded in the run manifest.

3. Draft → measured feedback
A first pass abridges the original source. Code counts the prose and each paragraph, then calculates the exact change needed to reach the fixed target.

4. Evaluate cuts → revise
A second call evaluates candidate cuts and dependencies, then returns a complete revision. Code recounts it and checks protected text. Both responses are preserved; no third generation pass is added.

No chapter-specific preservation choices were written or edited by the coding assistant. Production abridgments and earlier experiments were retained only for comparison. Model and effort: Opus 5.5, medium. The model sees one fixed word target and section allocations adding to it. The second pass receives its own first draft with mechanical counts. Drafts from earlier experiments are withheld. The reusable command is forage draft-two-pass.
