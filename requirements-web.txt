# Pinned dependency set for the review app image (INSTALL_MODE=web).
#
# Without pins, every `fly deploy` resolves whatever is newest on PyPI, so a
# yanked or compromised release reaches production with nothing in the diff to
# show it. Regenerate inside the image the Dockerfile actually builds from, so
# the pins match the platform that will install them:
#
#   docker run --rm --platform linux/amd64 python:3.12-slim sh -c \
#     "pip install -q fastapi 'uvicorn[standard]' && pip freeze" \
#     > requirements-web.txt
#
# (then restore this header). Review the diff before deploying.
#
# The pipeline's own dependencies are deliberately absent: the web image
# installs forage with --no-deps, and nothing the app serves imports them.
